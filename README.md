## العربية

تطبيق أندرويد مفتوح المصدر لقراءة القرآن الكريم برسم المصحف الشريف (خطوط مجمع الملك فهد للطباعة - 604 صفحة) مع تلوين أحكام التجويد السبعة بدقة عالية، ويعمل **بالكامل بدون إنترنت**.

### المميزات الرئيسية
- **أحكام التجويد الملونة (أو المصحف العادي):** تلوين الحروف وفق أحكام التجويد السبعة المعتمدة مع دليل تفاعلي للألوان، وإمكانية التبديل إلى المصحف العادي بلون موحد.
- **قراءة مستمرة وسلسة (120Hz):** عرض متواصل للآيات مع حفظ لحظي لموضع القراءة، وتوسيط تلقائي للآية عند تدوير الشاشة بين الطول والعرض.
- **4 سمات مريحة للعين:** أسود عميق (OLED)، داكن كحلي (Dark)، ورق دافئ (Sepia)، وأبيض نهاري (Light).
- **دعم كامل للغتين العربية والإنجليزية:** يتبع لغة الجهاز تلقائياً مع إمكانية التغيير اليدوي من الإعدادات ودعم كامل للاتجاهين (RTL / LTR).
- **أدوات قراءة متقدمة:** نزول تلقائي مع تحكم دقيق بالسرعة، تكبير وتصغير الخط، إشارات مرجعية، تذكير بسورة الكهف يوم الجمعة، وبحث سريع باسم السورة أو رقم الصفحة أو نص الآية (يدعم البحث مثل `2:255`).
- **إبقاء الشاشة مضاءة:** تبقى الشاشة مضاءة تلقائياً أثناء التلاوة.

## English

An open-source, **100% offline** Android application (**Quran Tajweed**) for reading the Noble Quran rendered with authentic Madinah Mushaf calligraphy (604 per-page King Fahad Complex fonts) and accurate **color-coded Tajweed** layers.

### Key Features
- **Color-Coded Tajweed & Standard Mode:** Highlights the 7 standard Tajweed rules with an interactive color guide, plus an option to switch to a monochrome standard Mushaf.
- **Fluid Continuous Reading:** Smooth 120fps vertical scrolling with automatic reading-position saving, instant resume banner, and focal-centered orientation lock when rotating between portrait and landscape.
- **4 Eye-Comfort Themes:** Pure OLED Black, Dark Slate, Warm Sepia Paper, and Daylight White.
- **Full Bilingual UI (Arabic & English):** Automatically adapts to your device's default language (RTL for Arabic, LTR for English) with manual language switching in Settings.
- **Smart Reader Tools:** Variable-speed auto-scroll, customizable font size, bookmarks, Friday Surah Al-Kahf reminder, quick Surah/Ayah jump modal, and fast search by Surah name (Arabic/English), page number, or verse key (e.g., `2:255`).
- **Always-On Screen:** Keeps the display awake automatically while reading.
